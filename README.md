Portfolio Backend Rest Api

A lightweight backend API built with Node.js and Express to handle server routing, data validation, and response handling.

Description

Built as part of Project 2 at DecodeLabs, this server acts as the backend layer for managing project data. It features custom endpoints for fetching (`GET /projects`) and adding (`POST /projects`) data. It uses custom input validation to check incoming requests before processing them, returning proper HTTP status codes and standard JSON responses.

Setup and running

1. Clone the repo and move into the project directory:
   git clone https://github.com/Bilal310-c/DecodeLabs-Internship-backend.git
   cd project2-backend

2. Install dependencies:
   npm install

3. Start the server:
   node server.js

The server runs on `http://localhost:3000`. You can test the endpoints using Postman or your browser.
